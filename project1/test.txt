Data Preparation
Based on initial visualization and overview of the data, there are missing values in only 2 columns i.e. savings balance and existing debt
- Assumption can be made if existing debt is missing it should be 0, the person doesn't have a previous loan
- Assumption 2, would be for savings balance that these people hasn't reported it reason can be anything, so the imputation should be based group the annual income and monthly expense. eg. if we have a data where annual income is 111847.46	and monthly expense is 5482.05 that has savings balance is 128214.10. So someone close to same numbers would have avg saving balance of that group.
We have to make sure categorical columns like loan purpose and employment type should be represented in numerical values as regression models mostly deals with numerical data, so, label encoding is the way to go.
Next the outliers, quite important, so, as the data mimics the real world we have to go with the multi-variate outlier approach for annual income, as it's the deciding factor for recommended loan amount (will be proved with feature importance)
After doing this we would move on with skewness for target and predictor columns, so we could do log transformation if required.
High collinearity is also a problem for linear and logistic regression, so, a solution here would be a separate copy of the data, as tree based models are less prone to collinearity problem.
- For highly collinear features/columns, where possible combine or dropping one of the column is the way to go.
